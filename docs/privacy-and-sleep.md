# Privacy and sleep prevention

## Privacy

Tomito vlv stores only preferences in your local macOS user defaults. It has no accounts, analytics, telemetry, sync service, or network dependency.

## Notifications

The app asks macOS for permission to display a local notification when a timer phase completes. Declining permission does not stop the timer.

## Keep Mac awake

When **Keep Mac awake while timer is active** is enabled, Tomito vlv creates a macOS power assertion only while the timer runs. It releases that assertion when you pause, stop, skip, finish a phase, or quit the app. This does not change your system password or lock-screen settings.
